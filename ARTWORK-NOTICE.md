# Character artwork and affiliation

Meow Kitteh is an unofficial fan-theme project featuring Hello Kitty depictions. Hello Kitty is a Sanrio character. This project is not affiliated with, endorsed by, or sponsored by Sanrio.

The seasonal SVG illustrations were newly drawn for this project; no downloaded Sanrio images or logos are included. They depict an existing character and are not presented as an original character created by the project.

The MIT license covers original interface and tooling code, not third-party character or trademark rights. It does not grant a license to Sanrio intellectual property. Character depictions in `src/artwork/`, embedded into `dist/` and `run.sh`, and visible in screenshots are excluded from the project's blanket MIT grant. No claim is made that these fan illustrations can be commercially relicensed.
