# Meow Kitteh for Pi-hole

Four seasonal dashboard fan themes: Christmas Wishes, Easter Garden, Beach Summer and Halloween Fall.

The experimental prototype, screenshots and downloadable installer are on [develop](https://github.com/RamrattanN/pi-hole-meow-kitteh/tree/develop). Main is reserved for reviewed releases; no stable release or live Pi-hole runtime certification is available yet.

This is a separate collection from Galactic Network Defense. It is an unofficial fan project, not affiliated with Sanrio or Pi-hole. See [ARTWORK-NOTICE.md](ARTWORK-NOTICE.md) for character rights; the MIT license applies to original code only.
